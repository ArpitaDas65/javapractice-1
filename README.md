# ☕ Basic Java Practice

A collection of my **Java practice programs** while learning the fundamentals of Java programming.

This repository contains simple programs covering variables, data types, operators, conditional statements, loops, switch statements, and basic inheritance.

* Variables
* Data Types
* Operators

## 🚀 How to Run

Make sure Java is installed on your system.

### Compile

```bash
javac filename.java
```

### Run

```bash
java filename
```

For example:

```bash
javac hello.java
java hello
```
